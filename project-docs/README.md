# Project Documentation

This directory is an initialization marker for projects created from the template.
The base template intentionally contains no client requirements, domain glossary,
or project-specific decisions.

After initialization, place durable project context here. Use these standard files:

- `requirements.md` for functional requirements, non-functional requirements,
  constraints, and acceptance criteria.
- `glossary.md` for domain terms and their agreed meanings.

Agents must read the relevant parts of both files when they exist before planning
or changing affected behavior. Do not treat this marker as a requirement and do
not invent missing client or domain context.
